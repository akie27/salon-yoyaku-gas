# 美容室の予約台帳（Googleスプレッドシート版）

データをお店の Googleスプレッドシートに保存し、Google Apps Script（GAS）の Webアプリとして動く版です。
費用はかからず、お店の Googleアカウントだけで運用できます。

お店の名前は `src/Code.js` の `SHOP_NAME` で変えられます。担当者とメニューは、画面の「担当者・メニューの設定」から変えられます。

## フォルダ構成

```
salon-yoyaku-gas/
├── src/                       ← Apps Script にアップロードする中身
│   ├── appsscript.json        設定（タイムゾーン・Webアプリの公開範囲）
│   ├── Code.js                サーバー側：シートの読み書き・二重予約の確認
│   ├── index.html             画面の骨組み（include で下のファイルを埋め込む）
│   ├── css/*.html             見た目（<style> で囲んだもの）
│   └── js/*.html, js/ui/*.html 画面側の処理（<script> で囲んだもの）
├── dev/mock-gas.js            ブラウザだけで試すための「にせ Apps Script」
├── tools/preview.mjs          dev/preview.html を作るスクリプト
└── .clasp.json.example        clasp を使うときの設定のひな形
```

Apps Script では .css / .js ファイルを置けないため、HTML ファイルの中に `<style>` / `<script>` を書き、
`index.html` から `<?!= include('js/store'); ?>` のように埋め込んでいます。

## スプレッドシートの中身

`setup()` を実行すると（初回に画面を開いたときも自動で）次の4シートができます。

| シート | 列 |
|---|---|
| 予約 | ID / 日付 / 開始 / 分 / 担当ID / 担当名 / お客様 / メニュー / メモ / 状態 / 作成日時 / 更新日時 |
| お客様 | 名前 / 来店回数 / 最終予約日時 |
| 担当者 | ID / 名前 / 色 |
| メニュー | 名前 / 分 |

予約を取り消しても行は消さず、「状態」を「取消」にします。

## まず手元で試す（アップロード不要）

```
node tools/preview.mjs
```

`dev/preview.html` をブラウザで開くと、にせの Apps Script で一通り動きます。
データはブラウザ内に保存され、開発者ツールのコンソールで `__resetMock()` を実行すると消えます。

## Apps Script に載せる

### 方法A：clasp を使う（おすすめ）

1. お店の Googleアカウントで新しいスプレッドシートを作り、「拡張機能 → Apps Script」を開く
2. Apps Script の「プロジェクトの設定」でスクリプトIDをコピーする
3. https://script.google.com/home/usersettings で「Google Apps Script API」をオンにする
4. このフォルダで
   ```
   npm install -g @google/clasp
   clasp login
   cp .clasp.json.example .clasp.json   # scriptId を書き換える
   clasp push
   ```
   `src/css/tokens.html` は Apps Script 上では `css/tokens` という名前になります。

### 方法B：手で貼り付ける

Apps Script のエディタで、`src` の中と同じ名前のファイルを作って中身を貼ります。
HTML ファイルの名前は `css/tokens` や `js/ui/booking` のように、フォルダ名ごと（拡張子なし）にします。
`appsscript.json` は「プロジェクトの設定 → 『appsscript.json』マニフェスト ファイルをエディタで表示する」をオンにすると編集できます。

## Webアプリとして公開する

1. エディタで関数 `setup` を選んで実行し、権限を許可する（シートができます）
2. 「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
3. 表示された URL を、お店の Googleアカウントでログインした iPad の Safari で開く
4. 共有ボタン →「ホーム画面に追加」でアプリのように使えます

「自分のみ」にすると、お店のアカウントでログインしている端末だけが使えます。
スタッフが各自の Googleアカウントで使う場合は、「アクセスできるユーザー：Googleアカウントを持つ全員」にして、
Code.js の `doGet` でメールアドレスを確認する仕組みを足してください。

## 更新するとき

コードを直したら、「デプロイ → デプロイを管理 → 鉛筆 → バージョン：新バージョン → デプロイ」。
「新しいデプロイ」を作ると URL が変わり、ホーム画面のアイコンを作り直すことになるので注意してください。
公開前の確認は「デプロイ → デプロイをテスト」の URL（最新のコードで動く）が便利です。

## 押さえておきたい仕組み

- **ロック（LockService）**：保存処理は `withLock_` の中で1件ずつ順番に行います。2台の iPad で同じ枠を同時に押しても、後の方は「ちょうど今、予約が入りました」になり、二重予約になりません。
- **重なりの確認はサーバーで**：画面側でも確認していますが、最終判断はロックの中の `assertFree_` です。画面の情報は数秒古い可能性があるためです。
- **変更の通知（版番号）**：保存のたびに `version` を更新し、各端末は20秒ごと（と画面を表に戻したとき）に確認して、変わっていれば読み直します。シートを直接編集した場合も `onEdit` が版番号を進めます。
- **文字列として保存**：日付・時刻の列は書式を「書式なしテキスト」にしています。そうしないと「10:30」が時刻型に変わり、読み出し時にずれることがあります。
- **数式として解釈させない**：「=」などで始まる名前は先頭に `'` を付けて保存します（`safeText_`）。
- **Date は返さない**：`google.script.run` は Date 型を画面へ返せないので、日時は数値や文字列にして返します（`snapshot_`）。
- **バックアップ**：スプレッドシートの「ファイル → 変更履歴」で過去の状態に戻せます。
